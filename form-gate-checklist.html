Gate 1 — SOW Freeze Checklist

No contract is issued without this gate passing. All blocker items must be confirmed.

Written or documented — not a verbal acknowledgment.
PLC scope, low-voltage scope, and integration dependencies reviewed.
Estimate must come from technical leads — not from Sales or PM assumptions.
Classification drives lead time expectations and resource planning.
Third-party dependencies, legacy system unknowns, or timeline risks noted.

Gate 2 — Design Freeze Checklist

No build begins until this gate passes. All blocker items must be confirmed.

FSD is the contract between requirements and build. No baseline = no build.
Integration surface with customer or third-party systems is defined and agreed.
Technical approach, data model, and integration patterns defined before build begins.
All parties understand that post-freeze changes require a formal CR.
Build cannot start without a working development environment.
How will we know when this is done? Acceptance criteria defined before build starts.
Named developers assigned, schedule locked, competing commitments resolved.

Gate 3 — Site Readiness Checklist

No travel approved. No commissioning begins. All blocker items must be confirmed.

All FSD-in-scope features complete, tested, and signed off in staging.
PLC programs tested, I/O mapping verified, controls documentation current.
No unapproved open scope. Every CR has a status.
PM has confirmed with customer. We do not travel to an unready site.
End-user training, admin training, and go-live support plan agreed with customer.
Who is on-call, escalation path, defect SLA, and support window defined.
If go-live fails, what is the recovery plan? Customer informed of contingency.
