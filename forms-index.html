Governance Rules Summary
  • Intake form is required for every project before it enters the pipeline. No named TPM, SW Lead, and Controls Lead = project does not start.
  • Gate 1 (SOW Freeze) must pass before any contract is issued. Sales does not sign without SW + Controls sign-off.
  • Gate 2 (Design Freeze) must pass before build begins. No FSD baseline = no development.
  • Gate 3 (Site Readiness) must pass before any travel is approved. SW + Controls confirm readiness. PM confirms customer site.
  • All customizations require a Change Request before work begins. Verbal requests are not work orders. No CR = no work.
  • Gate bypasses require leadership approval — named approver, documented exception, risk ownership assigned.
  • All forms submit via email. Update the to email address in each form before deploying. Replace your-team@yourcompany.com.
Setup
To configure email submission: Open each form file and find the line const to = 'your-team@yourcompany.com'; near the bottom of the file. Replace it with your team's actual email address. Each form will email its data to that address when submitted.

To host these forms: All files are self-contained HTML — no backend required. Upload the folder to any static hosting service (SharePoint, internal intranet, GitHub Pages, Azure Static Web Apps, Netlify, etc.). All links between documents use relative paths and will work as long as the files stay in the same folder.
